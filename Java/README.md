# Project Title Paint App

A Paint app that is vector based and has a variety of tools to draw with. It has a variety of features. 

## Instructions for Build and Use

Steps to build and/or run the software:

1. Make sure you have the necessary software and/or libraries installed. See the "Development Environment" section below for details.
2. Run PaintApp to start the from an IDE.
3. If you want to build the program, create a .jar file and run it using the command line. 

Instructions for using the software:

1. Tools are at the top of the screen. The settings for the tools below.
2. Draw and the canvas, and save or export your work when complete.
3. The included "colors_by_tone_sorted.pdf" file can be quite useful when picking a hex. Copy and paste the color you want to use from the PDF into your code.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* You will need Java 17 or higher to run this program. You can download it from [here](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html).
* No extra libraries are needed to run the program.
* I used JetBrains IntelliJ IDEA to develop the program, but you can use any Java IDE or text editor you prefer.
