# Factorial Calculator (Update)

A factorial calculator using recursion. It uses enum and structs as the extra for the project, thought the struct only has one data type. The enum handles the errors. It meets all other requirements, and allows user input and a verbose feature. Mostly built with AI which taught, yours truly, me. 
## Instructions for Build and Use

Steps to build and/or run the software:

1. Install Rust (if not installed)
2. run 'cargo build --release' in directory of project
3. run 'cargo run --release'

Instructions for using the software:

1. type y or n for verbose
2. type a number below 21
3. type q to quit

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* cargo 1.86.0 w/ Rust
